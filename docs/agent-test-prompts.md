# Agent 测试提示词集

覆盖 Agent 全部能力点的测试提示词清单。配套自动执行脚本：`test/agent/test_agent_prompts.py`。

测试用户：`xiaoming`（身高175/体重78/男/32岁/减重目标/高血压+高血脂/花生海鲜过敏/少油不辣）

---

## 一、基础对话（无工具）

| # | 提示词 | 预期行为 |
|---|--------|---------|
| 1.1 | 你好 | 正常回复，thinking + chunk + done 事件，无工具调用 |
| 1.2 | 你是谁？ | 介绍自己是 NutriGo 营养师 |
| 1.3 | 今天天气怎么样 | 礼貌说明自己只擅长营养，不硬答 |

## 二、工具：lookup_food_nutrition（查营养）

| # | 提示词 | 预期行为 |
|---|--------|---------|
| 2.1 | 苹果每100克有多少热量和蛋白质？ | 调用工具，返回苹果精确营养数据 |
| 2.2 | 查一下"红烧"类食物的营养 | 精确查不到时走模糊搜索，返回相似结果 |
| 2.3 | 查"炸鸡"的营养成分 | 返回数据含热量/蛋白/脂肪/碳水 |
| 2.4 | 查一个不存在的食物"火星汉堡" | 返回"未找到"类提示，不崩溃 |

## 三、工具：get_user_profile（查档案）

| # | 提示词 | 预期行为 |
|---|--------|---------|
| 3.1 | 你认识我吗？我的档案是什么 | 调用工具，返回身高/体重/目标/基础病/过敏 |
| 3.2 | 根据我的情况，我的BMI是多少？ | 调用工具拿到数据后计算 BMI 并解读 |

## 四、工具：get_diet_history（查饮食记录）

| # | 提示词 | 预期行为 |
|---|--------|---------|
| 4.1 | 我今天吃了什么？ | 调用工具，返回当天饮食记录 |
| 4.2 | 帮我分析一下今天吃的营养够不够 | 调用工具，基于记录做营养分析 |

## 五、工具：search_nutrition_knowledge（搜知识库）

| # | 提示词 | 预期行为 |
|---|--------|---------|
| 5.1 | 糖尿病患者的饮食原则是什么？ | 调用工具，引用教材知识回答 |
| 5.2 | 高血压的膳食建议有哪些？ | 调用工具，引用 DASH/限盐知识 |

## 六、多工具协同（关键测试）

| # | 提示词 | 预期行为 |
|---|--------|---------|
| 6.1 | 我有高血压和糖尿病，结合我的档案和专业知识给我饮食建议 | 至少调用 get_user_profile + search_nutrition_knowledge 两个工具 |
| 6.2 | 看看我今天的饮食，结合我的减重目标给建议 | 至少调用 get_diet_history + get_user_profile |

## 七、个性化（档案联动）

| # | 提示词 | 预期行为 |
|---|--------|---------|
| 7.1 | 我想减重，帮我定一个每天摄入热量的目标 | 调用档案，算出 BMR/TDEE，给出热量缺口 |
| 7.2 | 我对花生海鲜过敏，推荐点高蛋白食物 | 明确避开花生海鲜，推荐替代蛋白源 |
| 7.3 | 我有高血压，给我一周的控盐食谱 | 结合档案+知识库，给出限盐方案 |

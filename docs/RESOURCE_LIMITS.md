# 请求与资源限制

核对日期：2026-09-20，适用于单实例 Go + Agent。升级不会删除已有照片或饮食记录；达到配额后拒绝新的上传。

## 请求入口

| 入口 | 限制 | 超限行为 |
|---|---|---|
| Go / Agent 普通请求体 | 64 KiB；按实际字节计数后再解析 JSON，包含没有 Content-Length 的请求 | `413` |
| 图片上传 | 单文件 10 MiB，multipart 整体 11 MiB | `413` |
| 压缩请求体 | 只接受未压缩/identity | `415` |
| 普通请求体同时读取数 | 每个服务 64 个，无等待队列 | `503` |
| Go 读取期限 | 请求头 5 秒、总读取 30 秒 | 中止超时读取 |
| Agent 请求体读取期限 | 总计 15 秒 | `408`；连接断开时无法保证响应 |
| Caddy | 普通请求 64 KiB、上传 11 MiB；请求头 5 秒、请求体 30 秒 | `413` / 中止超时连接 |

网关和应用分别限制字节。Go 上传在鉴权和准入后才解析 multipart；Go 还有 60 秒写入/空闲超时。Caddy 不设置短 SSE 写入超时，Agent 无请求体 GET 不预读连接，聊天保留 15 秒心跳及 `CHAT_TIMEOUT` 总生成期限。网关使用 Caddy [request_body](https://caddyserver.com/docs/caddyfile/directives/request_body) 和 [timeouts](https://caddyserver.com/docs/caddyfile/options#timeouts)。

## 图片配额与上传

| 配置 | 默认值 | 含义 |
|---|---|---|
| `IMAGE_USER_MAX_BYTES` | `536870912`（512 MiB） | 每用户照片累计字节 |
| `IMAGE_USER_MAX_FILES` | `1000` | 每用户照片张数 |
| `IMAGE_TOTAL_MAX_BYTES` | `10737418240`（10 GiB） | 全站照片累计字节 |
| `UPLOAD_MIN_FREE_BYTES` | `2147483648`（2 GiB） | uploads 所在文件系统剩余空间底线 |
| `UPLOAD_RATE_PER_MIN` | `10` | 每用户每分钟补充的令牌数 |
| `UPLOAD_RATE_BURST` | `3` | 瞬时令牌桶容量 |

同时上传最多每用户 1 个、全站 4 个；全站照片上限 20,000 张。速率/并发超限返回 `429` 和 `Retry-After`；个人容量/张数满返回 `409`；全站配额或磁盘不足返回 `507`；无法查询配额返回 `503`。非法或非正 Go 配置回退默认值。

读取前预检磁盘，为所有在途请求各预留最多 11 MiB 余量。解析到文件大小后，在进程互斥锁内查询数据库用量并预留字节，再写文件/入库，结束时释放预留。这样并发请求不能同时占用同一份剩余额度。令牌桶最多保存 10,000 个用户，空闲 1 小时清理，达到上限时拒绝新条目。

新删除任务保存原用户和字节，文件未成功清理时仍计入配额，完成后归还。升级前已有任务缺少这些字段时默认值为 0，无法恢复已丢失的用户/大小信息，但全站张数和真实磁盘余量仍覆盖这些文件。字节配额只统计照片记录和待删除任务；磁盘余量也反映模型、备份和其他文件占用。余量预检不是文件系统硬配额，外部进程仍可能在检查后写满磁盘；上传写入失败会按现有流程回收文件。

## 照片分析

`/api/analyze-meal` 与 `/api/identify-food` 共享每用户 1 个、全局 `PHOTO_MAX_ACTIVE`（默认 4）个任务名额。旧 CLIP 额外限制为 1 个。图片归属校验和缓存检查后先取得名额，再下载二进制和进入模型；无名额立即 `429`。同图并发分析也拒绝，完成后重试复用缓存。

从 Go 流式读图最多 30 秒/10 MiB，无 Content-Length 时同样计数；不先无限读入内存。解码前限制每边最多 8192、总像素最多 2,000 万。新版保留模型 HTTP 45 秒和调用整体 48 秒限制。

`PHOTO_REQUEST_TIMEOUT` 默认 60 秒，响应等待超时返回 `504`。Python 无法安全强杀运行中的 CPU 线程，所以取消/超时后任务仍占用名额，直到实际结束才释放并取走异常或缓存结果。永久卡住的线程需要检查并重启 Agent，不提前释放名额来积累更多线程。

## 部署与验证

此升级需更新 Go、Agent 及当前使用的 Caddy 配置。Go 自动迁移删除任务字段，升级前先备份。容量来自数据库，重启不会清空已用空间；速率、在途预留和模型名额在进程内，重启会重置速率。多实例/多 worker 需要共享配额事务和分布式准入，不能直接横向复制后仍声称全局限额有效。累计 AI 费用预算、容器硬资源配额和边缘抗 DDoS 仍需单独建设。

测试覆盖请求大小边界/分块/慢读取、未认证大 JSON、上传并发容量预留、磁盘/数据库失败、删除后额度归还、新旧分析共享准入、取消/超时后线程占用、10 请求识别突发，以及网关大小限制和 SSE 转发。使用隔离数据库、模型替身，不在生产压测。
